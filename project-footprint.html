Original ambition

Not a chart.
A system.

The project started with a real-time market chart, but the actual goal was larger: collect trustworthy data, preserve it for long-term research, run a quant machine without look-ahead, simulate realistic execution, and publish evidence of performance without revealing the algorithm itself.

Progress includes
the wrong turns.

This is not a complete commit history. It records the decisions that changed the architecture or revealed a false assumption.

  1. Origin
    ScopeArchitecture

    The chart became a data contract.

    Samsung Electronics, SK hynix, QQQ, and VOO became the first test universe. Five-minute OHLCV, trades, and order-book state were separated from daily fundamentals and investor flow. Older five-minute data would leave the hot database only after 120-minute aggregation and verified Parquet archiving.

  2. Foundation
    SupabaseNon-destructive migration

    A versioned store replaced the first prototype.

    The initial one-minute, single-symbol structure was not deployed as the final pipeline. A new schema added instruments, five-minute bars, order flow, order-book summaries, 120-minute bars, point-in-time fields, and archive audit records without deleting the original tables.

  3. Collection
    KIS WebSocketCloud Run

    The first domestic collector passed preflight.

    A scheduled Cloud Run Job was built to subscribe to Korean trade and quote feeds for the two semiconductor stocks. Authentication, Supabase access, and instrument registration passed preflight; weekday startup was scheduled for 08:55 KST, with operating cost accepted as a measured pilot rather than assumed to be free.

  4. Detour 01
    Missed sessionBackfill limit

    Deploying after the open left a hole.

    The first live deployment happened after the Korean session had begun, so that day's intraday stream could not be reconstructed from a collector that was not running. REST backfill recovered OHLCV, but not the missing historical trade and order-book stream. A close catch-up step was added after the final domestic bar stopped at 15:15.

  5. History
    5m120m1D

    Available history was measured, not assumed.

    Historical jobs populated domestic intraday data and multi-asset daily data. The overseas probe showed roughly one month of regular-session five-minute QQQ and VOO bars through the selected provider at that moment—1,638 rows per instrument—so the public record now distinguishes provider availability from the five-year history originally imagined.

  6. Detour 02
    Public boundaryReversal

    Administrator-only access was the wrong product.

    The dashboard briefly moved toward private administrator access. That decision was reversed: visitors should be able to inspect ordinary market charts and completed paper-trading results without signing in. The protected boundary is the intellectual property—features, weights, parameters, model scores, future signals, credentials, and private raw records.

  7. Detour 03
    Apple placeholderSilent buttonsUI iteration

    A polished chart can still be wrong.

    One embedded chart displayed Apple and Cboe One despite a Samsung header. Another iteration restored the right data but removed useful chart tools. QQQ and VOO then failed silently when configuration and in-flight requests disagreed. The result is a hybrid view: the collected Supabase feed for data truth, a separate provider-tools view, visible failure states, and a durable four-instrument selection path.

  8. Now
    PrototypeStill in progress

    The public surface exists; the trading system does not—yet.

    The site now exposes market-history views, provider tools, release controls, and a public Quant Live Lab shell. Korean collection and historical storage have working components. U.S. real-time collection, automatic cold archiving, the paper execution engine, and published strategy statistics are still unfinished.

Lessons carried forward

The process changed
the specification.

01

Data truth precedes display.

A responsive chart is not proof that the underlying feed is correct, current, or licensed for the way it is shown.

02

Backfill is not time travel.

OHLCV can repair many gaps, but it cannot recreate trade sequence, quote state, or a collector that was never connected.

03

Failures must be visible.

Silent buttons and stale labels turn configuration mistakes into misleading interfaces. The system should state what failed.

04

Public results need a private core.

Performance can be inspectable while the algorithm, future intent, credentials, and research assets remain protected.
